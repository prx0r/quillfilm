## 1. Function colors (locked 2026-10-19)

| Function | Hex | Meaning |
|---|---|---|
| Process / pulse | `#5EC4B6` teal | the carrier, continuity, alive — the relink pulse, waves, flow (palette lineage: /root/body) |
| Fire | `#E8102E` | THE flame + fire-element + violation/cut marks (family red law: never used casually) |

| Death-moment | `#F8FAFC` white flash | absence made visible: the shut-off stamp, ceasing events (family pause-white) |
| Designation | `#8B5CF6` violet | names/labels/constructs — chariot, "person", anything fiction-that-works (family premise-violet) |
| Citation / measurement | `#F5C76B` gold | quotes, sources, timers, figures — THE citation color (family law) |
| Background | `#07070a` | every frame behind content |
| Text | `#f3f1ec` / muted `#8d8b93` | narration, secondary |

Rules: gold NEVER decorates — it only cites/measures. Red never celebrates.
Ochre/silver/smoke appear ONLY inside element contexts (body fluid, ladder).
Teal = anything that continues; white flash = anything that ceases. These
oppositions (teal↔flash) are the film's color thesis.

## 2. Type
- Titles: Anton. Body/overlays: Inter Tight. Mono digits: gold.
- **Scripture serif rule (our signature):** any text quoted from a source
  (sutta, teacher, paper, WHO, Bardo Thödol) renders in SERIF (Georgia/
  Spectral) when on screen; narration/UI stays sans. Verse (Pāli) always
  serif + gold. The serif IS the citation.

## 3. Subtitles
- All speech: ink `#f3f1ec` (no comedy blue/red turn-switching — our clips
  are teachers, not set-ups landing punches).
- Exception: a joke in owner-speech gets no color either — the cut IS red,
  not the subtitle.
- Lower-third citation ticker (always present under clips): source in gold
  serif, short form ("MN 38" · "Thanissaro, Truth of Rebirth" · "Bardo Thödol,
  ch.11"). Never absent. This is our pause-timer-equivalent honesty device.

  stamp `0→1` — never narrated over.
- No sphere, no laugh ticks: those measure comedy; ours measures being.

## 5. Glyph set (per tradition transfer — TRANSFER-VISUALS.md is the spec)
- Relink pulse: teal dot jumping a hairline gap without breaking (Theravāda).
- Withdrawal: teal drain inward + hue→cold (Yogācāra).
- Lotus arrival: gold light in, close (Pure Land).
- Contour-slip: violet outline, playhead slipping, fill denied (Madhyamaka).
- Dissolution ladder: 5 steps ochre→silver→red→smoke→flash (Tibetan) —
  the money shot; only place all five element colors appear together.

## 6. Motion law (gcomedy's law, our clause)
- Hard cuts: jokes, beat changes, cards. Dissolves: STATE TRANSITIONS ONLY
  (alive→dying→element-change→ceased). Never crossed — a joke never gets
  a dissolve; a death never gets a cut.
- Deterministic render (HyperFrames seek(t)), probe stills before full render.
- Silence: black open + coda only; mid-film holds 1–3s (the skip-marker at
  the Nanavira section may hold 4s — flagged, once).
